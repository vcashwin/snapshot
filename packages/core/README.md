# @paper-snapshot/core

DOM picker and computed-style HTML serializer extracted from [Paper Snapshot](https://paper.design/snapshot-extension).

**Full documentation:** [github.com/vcashwin/paper-snapshot](https://github.com/vcashwin/paper-snapshot)

## Install

```bash
pnpm add @paper-snapshot/core
```

## Quick start

```ts
import { captureAndCopy } from "@paper-snapshot/core/capture";

await captureAndCopy();
```

See the [monorepo README](https://github.com/vcashwin/paper-snapshot#readme) for React, Electron, and tree-shaking docs.
